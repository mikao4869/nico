# 부모 태그 자식 태그 

이런식에 html이 있다고 생각을 해보자.


  <div id="quote">
      <span></span>
      <span></span>
    </div> 

이런식일때 js 에서 불러오는것은 어떻게 할까?


    const 이름 =document.querySelector("# quote span")

여기서 불러오는 `span`은 2번째 일까? 첫번째 일까?


헷갈림을 방지 하기 위해서는 이렇게 해야한다.


`span:first-child` 이런식으로 표시
 

ex)


    const 이름=document.querySelector("#quote span:first-child")

이런식으로 하면 span이 가리키는것이 `첫번째` 인것을 확인할수 있다.

***

### 두번째 span을 불러오고 싶을때는?


`span:second-child` 이런식으로도 할수 있다.
