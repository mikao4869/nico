# createElement

html에서도 할수 있는것을 js에서 하는듯한 느낌이랄까


ex)


js

      const li=document.createElement("li");
      const span=document.createElement("span");
      const button=document.createElement("button");

지금 이거는 js에서 `li`,`span`,`button`을 만드는것으로 볼수 있다. 

이건 마치


html

ex)

    <span><span/>

이렇게 html에서 만든거랑 똑같다고 볼수 있을까
