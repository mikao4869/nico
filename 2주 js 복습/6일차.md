# 3 .


      What is the difference between using className and classList
      (className과 classList의 차이는?)

      정답: className replaces all classes, classList doesn't
      (className는 모든것을 교체할수 있지만 
      classList는 그렇지 않다)


    해석:   

    className: 새로운 클래스를 추가하면 기존 클래스가 모드 덮어 씌워진다. 

    classList: 기존 클래스를 유지하면서 특정 클래스를 추가하거나 제거 할수 있다.
