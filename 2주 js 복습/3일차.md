# 1. function의 arguments를 왜 사용하나?

    Why do we use ‘arguments’ on functions?
    (왜 우리는 function애서 argument를 사용하나?)


    1. To get a value from a function. 
    (function으로부터의 value의 값을 받기 위해서)

    2. To send a value to a function.
    (value을 function으로 보내기 위해서)


+ 답: 2
+ 해석: 1번이 하는것은 `return`이 하는것이다. `argument`는 함수 내부로 값을 전달하는 역할 을 한다.
