주제: resize 의 기준마다 배경색이 바뀌게 해야하는거

### 조건: if,else 문을사용하는거



# 코드 


      const h2=document.querySelector("h2");


      document.body.style.backgroundColor="#87CEEB";  // 설정 색 지정

      function handle(){
          let NewBackgroundColor;  //새로운 배경색 
          let width=window.innerWidth;  //window.innerWidth를 많이 사용하니깐 width로 지정
        if(width<500){
          NewBackgroundColor="#87CEEB";  //배경색 변경
        }
        else if(500<width&& width<1000){   //&& 사용
          NewBackgroundColor="#8977AD" ;

        }
        else{
          NewBackgroundColor="#FFD400" ;
        }

        document.body.style.backgroundColor = NewBackgroundColor;  //이게 가장 중요!
      }

      window.addEventListener("resize",handle);

      

# 어려웠던것, 힘들었던 것:

정도만 알면 된것 같다. 내가쓴 코드는 그런것을 사용하지 않았지만 조건이 if else문을 사용했기 때문에 안 떨어졌으면 좋겠다. ..


헷갈렸던 `Window.innerWidth` 에 대해서 설명을 해보자


## Window.innerWidth 

뭐냐면 너비의 창의 픽셀을 알고 싶을때 사용하는 코드인것 같다.

그래서 코드를 작성할때 `Window.innerWidth` 이거를 사용해서 if,else로 기준을 두고 그 기준이 넘으면 색상이 바뀌게 했다. 


# css 쓰지 않고 js로 배경색 바꾸기


이것도 코드 하면서 어려웠던 점이었는데 


`document.body.style.backgroundColor `는 js에서 css를 바꾸는 코드이다. 


이 코드를 쓰지 못해서 막혔었는데,

새로운 배경을   `NewBackgroundColor` 로 정하면 뭐하냐. 인식을 하지 못하는데

이 코드는 바뀐 새로운 배경색깔을 인식해 보여주기로 한 코드이다. 

         document.body.style.backgroundColor = NewBackgroundColor
