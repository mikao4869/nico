# 목표: 크리스마스가 언제 오는지 d-day 하는거

# 코드 

      const clockTitle = document.querySelector('.js-clock');


      function getClock(){
        const now=new Date();   //현재시각
        const christmas = new Date('2025-12-25T00:00:00');  //크리스마스 시각
        const time=christmas-now;   //크리스마스 시각- 현재 시각= 남은 시각
        const days = Math.floor(time / (1000 * 60 * 60 * 24));   /일 구하는
        const hours = Math.floor((time / (1000 * 60 * 60)) % 24);  / 시간
        const minutes = Math.floor((time / (1000 * 60)) % 60);   //분
        const seconds = Math.floor((time / 1000) % 60);  / 초

        clockTitle.innerText=`${days}d ${hours}h ${minutes}m ${seconds}s`  //화면에 보여지게끔
      }
      getClock();
      setInterval(getClock,1000);


# 설명


1. setInterval

      setInterval(getClock,1000);

`setInterval`는 몇초마다 반복해서 일어나는거: 
 + 코드 설명: 1초마다 반복해서 getClock 함수를 불러옴 


2. Math.floor

       const days = Math.floor(time / (1000 * 60 * 60 * 24));   /일 구하는
        const hours = Math.floor((time / (1000 * 60 * 60)) % 24);  / 시간
        const minutes = Math.floor((time / (1000 * 60)) % 60);   //분
        const seconds = Math.floor((time / 1000) % 60);  / 초

`Math.floor`는 주어진 수와 같거나 작은 수 중에서 가장 큰 정수를 반환하는 함수 

+ 정확한 정수(즉 시간, 분등등)를 구하기 위해서 Math.floor를 사용한것 같음 
+ 몰랐던 것:  난 이렇게 구하지 않고  


        clockTitle.innerText=`${chrismas.getDay()}d:${chrismas.getHours()}h:${chrismas.getMinutes()}m:${chrismas.getSeconds()}s`}

이렇게 길고 한줄로 구했었는데, 이럴 필요가 없고, 저렇게 구할수 있다니..

`time / (1000 * 60 * 60 * 24)` 이런것에 관한 개념이 없었다. 


#### 시간 공식 

+ day 구하는 공식: `(1000 * 60 * 60 * 24)`
+ hours 구하는 공식: `(1000 * 60 * 60) % 24`
+ minutes 구하는 공식: `(1000 * 60)) % 60)`
+ second 구하는 공식: `(time / 1000) % 60)`
